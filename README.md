# Cross Selling TIM + Cartão de TODOS

Plataforma de acompanhamento de resultados de vendas do plano TIM Controle
+ Cartão de TODOS, por regional (EQUATORIAL, SAO PAULO MINAS, INTERIOR,
COSTA LESTE, CENTRO SUL).

## Funcionalidades
- Dashboard executivo com ranking de vendas por regional
- Operacional (consolidado + parcial do dia) com plano de ação por franquia
- Ranking de vendedores
- Projeções de fechamento
- Estratégias & Script e Material de Apoio
- Admin com upload de base .xlsx e configuração de metas por regional

## Deploy
Publicado na Vercel. A cada push na branch principal, o deploy é automático.
